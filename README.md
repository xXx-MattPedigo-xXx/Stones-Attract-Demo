# Stones-Attract-Demo
Public demo for Stones Attract mobile game.

**Play it:** https://xxx-mattpedigo-xxx.github.io/Stones-Attract-Demo/

Place magnetic stones inside the cord without letting them snap together. If stones snap, you take them all back. Push the cord outward with a stone to reshape the play area.

- **Solo (timed):** place all 12 stones before the clock runs out. Easy 2:00, Normal 1:30, Hard 1:00.
- **Pass & play:** 2–4 players on one device. First to empty their tray wins.

Tap **New** to pick a mode.

This repository only hosts the built demo. Source code lives in a separate private repository.
