# Stones-Attract-Demo
Public demo for Stones Attract mobile game.

**Play it:** https://xxx-mattpedigo-xxx.github.io/Stones-Attract-Demo/

Place magnetic stones inside the cord without letting them snap together. If stones snap, you take them all back. First player to empty their tray wins. Push the cord outward with a stone to reshape the play area.

This repository only hosts the built demo. Source code lives in a separate private repository.
